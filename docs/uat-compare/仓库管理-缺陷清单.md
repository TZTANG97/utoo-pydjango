# 愉兔检测管理平台 UAT — 仓库管理 对比缺陷清单

- 对比日期：2026-09-14
- 新站（Python）：https://uat.utoodev.laide.tech/#/admin/inventory/warehouses  
  （菜单：库存管理 → 仓库管理）
- 旧站（Java）：https://uat.utoo.laide.tech/console/storeHouse/storeHouseList.htm  
  （外层 console；菜单：库存管理 → 仓库管理）
- 抽样仓库：`ce233` / 仓库1345；另有 `测试` / 测试111
- 说明：旧站打开仓库列表可能再次出现登录墙（与库存页类似）

---

## P0 / 高 — 数据或检索易错

### BUG-WH-01 列表负责人展示与检索字段不一致（新站更易误导）
- **现象**：
  - 新站列表 `ce233` 负责人显示 **韩想**；编辑表单为 **CS04（韩想）**
  - 旧站列表与编辑均为 **CS04**
  - **两边**按「韩想」筛选均为 **0 条**；按 **CS04** 均可命中 1 条
- **影响**：用户按页面看到的姓名搜索会认为系统无数据；新站「显示姓名、按编码搜」不一致更严重
- **建议**：列表与筛选统一（均姓名、均编码，或支持姓名+编码）；至少在筛选框 placeholder 标明「工号/编码」

### BUG-WH-02 配置页「仓库位置」首屏数据新旧不一致
- **操作**：`ce233` → 配置
- **地块**：两边均有地块 3 / 2 / 1（新站多「创建时间」列）
- **位置首屏**：
  - 新：连续位置如 `1-1`…`1-10`，序列号 1–10 等
  - 旧：出现重复位置及序列号如 `6262217938`、`C-W10XB-149`、`C-W10XB-150` 等
- **文案**：新「已放置」vs 旧「已放置产品」
- **影响**：库位/在架设备对账困难，可能是同步或查询条件不同
- **建议**：按位置标识对账全量导出比对；核对配置接口过滤条件

## P1 / 中 — 字段模型与交互差异

### BUG-WH-03 编辑表单字段集合不一致
| 项 | 新站 | 旧站 |
|---|---|---|
| 形态 | 弹窗「编辑仓库」 | 独立页/标签「编辑仓库」 |
| 状态 | 有（启用） | 无 |
| 手机/电话 | 「手机」可编辑 | 「联系电话」只读展示 |
| 地址 | 「地址」 | 「详细地址」 |
| 备注 | 有 | 有 |
| 关闭 | 取消 + X | 仅保存，靠关标签 |

- **建议**：明确迁移后字段模型；旧站电话只读是否为权限设计需产品确认

### BUG-WH-04 配置页能力/列不一致
- 新：顶部有「返回」；地块表有创建时间；位置表无左侧复选框
- 旧：无返回；地块无创建时间；位置表有复选框；操作文案「删除」vs 新「删除位置」
- **建议**：对齐必要列与返回导航；差异写入迁移说明

### BUG-WH-05 列表列不一致（产品决策）
- 新有：**状态、创建时间**；无备注列
- 旧有：**备注**；无状态、创建时间；有序号列
- 筛选命名：新「负责人/手机」vs 旧「联系人/联系电话」
- 工具栏：新增仓库 vs 添加仓库；操作「停用」vs「禁用」

### BUG-WH-06 旧站仓库页可能二次登录
- **现象**：会话失效或直开 `storeHouseList.htm` 时再次出现 `#userName/#password` 登录墙
- **建议**：与库存页一并排查会话共享

### BUG-WH-07 新站无整页「清空筛选」
- 仅有输入框单项清除；需手动清空后点查询（本次清空后再查可恢复 2 条，功能可用但体验弱于统一清空按钮）
