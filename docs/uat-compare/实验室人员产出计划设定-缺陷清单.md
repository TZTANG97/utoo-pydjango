# 愉兔检测管理平台 UAT — 实验室人员产出计划设定 对比缺陷清单

- 对比日期：2026-09-14
- 新站（Python）：https://uat.utoodev.laide.tech/#/admin/digital/test-plan
- 旧站（Java）：https://uat.utoo.laide.tech/console/index/main.htm → 数字化中心 → 实验室人员产出计划设定  
  （内嵌：`/console/testUserPerformance/load.do?rel=performance_load`）
- 抽样账号行：C01 / AC01（及筛选用例）

---

## P0 / 高 — 功能错误或数据展示明显异常

### BUG-01 旧站列表「注册时间」全部显示为 NaN
- **站点**：旧站
- **现象**：列表「注册时间」列普遍显示 `NaN-aN-aN aN:aN:aN`
- **新站对照**：同数据行显示正常，如 `2026-08-06 10:52:00`
- **复现**：进入「实验室人员产出计划设定」列表即可；筛选后仍复现
- **影响**：无法从列表判断注册时间；疑似日期序列化/前端格式化错误
- **建议**：核对接口返回的时间字段类型与前端格式化逻辑

### BUG-02 旧站「查看」弹层内容未正确渲染
- **站点**：旧站
- **操作**：勾选首行 C01 → 顶部「查看」
- **现象**：弹窗标题为「查看」；动态区域几乎空白，仅残留 `AC01`；表头/「年份」「目标金额」等字段未显示
- **新站对照**：标题「历年/月目标」，表头「年份、目标金额」结构完整（当前内容为「暂无数据」）
- **影响**：旧站无法通过「查看」核对历年/月目标
- **建议**：检查查看弹层数据加载、iframe/表格初始化

### BUG-03 旧站「设定」表单未预填关键字段
- **站点**：旧站
- **操作**：勾选 C01 → 顶部「设定」
- **现象**：年份为空（placeholder「年份选择」）；设定值为空；设定值旁有红色警告图标但无说明文案
- **新站对照**：标题「设定产出目标」；年份预填 `2026`；目标金额预填 `0.00`；有加减控件
- **影响**：用户易误以为无默认值或校验失败原因不明
- **建议**：对齐新站预填逻辑；补全校验提示文案

## P1 / 中 — 体验不一致或易误导（新旧应对齐或明确产品决策）

### BUG-04 「清空」只清控件、不自动重新查询（新旧皆有）
- **站点**：新站 + 旧站
- **现象**：点击「清空」后，筛选控件恢复默认，但列表仍停留在上一次筛选结果；需再点「查询」才恢复宽表
- **影响**：用户以为已恢复全量列表，实际仍是筛选结果
- **建议**：清空后自动触发一次查询；或在文案/交互上明确提示

### BUG-05 旧站「设定」缺少明确「取消」
- **站点**：旧站
- **现象**：设定弹层仅有「保存」「清空」，关闭只能靠右上角 X
- **新站对照**：有「取消」「保存」
- **建议**：补「取消」或统一关闭文案，避免误点「清空」

### BUG-06 协助者展示格式不一致（需确认是否缺陷）
- **站点**：对比
- **现象**：第 1 条协助者，新站显示 `协助者01`，旧站显示 `01`
- **影响**：可能是展示差异而非数据错误
- **建议**：确认产品期望展示规则后统一

## P2 / 低 — 交互/布局差异（产品设计差异，非必改）

### DIFF-01 操作入口不同
- **新站**：每行内「设定」「查看」
- **旧站**：勾选行后点顶部「设定」「查看」；姓名可点进用户详情
- **说明**：功能可达，路径不同

### DIFF-02 部门筛选交互不同
- **新站**：筛选栏内树形下拉「全部部门」，选完需点「查询」
- **旧站**：左侧固定部门树，点击节点即自动刷新；标题变为「用户列表--{部门}」
- **说明**：筛选结果一致（如「实验测试部门」均为 6 条）

### DIFF-03 旧站弹层布局偏宽
- **现象**：旧站弹层出现横向滚动条，布局较新站臃肿
- **建议**：按需收敛弹层宽度

### DIFF-04 性别控件实现不同
- **新站**：自定义下拉
- **旧站**：原生下拉
- **说明**：筛选「女」两边均为 20 条，结果一致
