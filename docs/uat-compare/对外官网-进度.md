## 关键发现

1. 两站公共信息架构基本一致：首页 → 实验分类 → `test_detail` 详情；公司介绍独立页；讨论和个人中心需要登录。
2. NEW 的主要可见差异是浅灰页面底色、白色圆角卡片、右侧白色工具条，以及详情轮播按钮的可读标签；OLD 为白底/橙色图标工具条。
3. 两站均含明显 UAT/测试数据和破图资源，已记录在 `对外官网-缺陷清单.md`。
4. 讨论、预约、订单、资产等后续 parity 需要用户可协助完成微信扫码或提供测试账号；当前按要求停在登录墙。
