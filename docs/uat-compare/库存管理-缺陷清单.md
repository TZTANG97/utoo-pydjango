# 愉兔检测管理平台 UAT — 库存管理 对比缺陷清单

- 对比日期：2026-09-14
- 新站（Python）：https://uat.utoodev.laide.tech/#/admin/inventory/list
- 旧站（Java）：https://uat.utoo.laide.tech/console/inventory/inventoryList.htm  
  （菜单：库存管理 → 库存管理）
- 说明：旧站进入库存页可能再次要求登录（与控制台主页会话不完全共用）

---

## P0 / 高 — 数据范围或核心结果不一致

### BUG-INV-01 新旧库存数据集/可见范围严重不一致
- **现象**：
  - 新站列表约 **326** 条，UAT 实验总量约 **1676**，约 33 页
  - 旧站显示 UT 实验租用总数量约 **100**，约 6 页（10 条/页）
  - 默认首页排序与首屏商品完全不同（新站以 CMW100/ZNB 等开头，旧站以 GP20/模块等开头）
- **影响**：无法用「同页对比」直接验收库存迁移；需先确认 UAT 是否同一数据源、同一过滤条件（租用范围/公司/仓）
- **建议**：核对后端查询条件、租用总量口径、默认排序与聚合规则（按型号聚合 vs 单条）

### BUG-INV-02 新站存在、旧站查不到的关键样例
| 筛选条件 | 新站 | 旧站 |
|---|---|---|
| 产品名称 `CMW100` | 1 条（KC2020100148/156，数量 2/2，序列号 108435、108424） | **0 条** |
| 产品型号 `ZNB8` | 1 条（KC2021120035，1/1，107253-uL） | **0 条** |
| 产品序列号 `108435` | 1 条（CMW100） | **0 条** |
- **影响**：迁移验收失败；旧站缺失设备或过滤过严
- **建议**：按库存编号/序列号在库核对是否未同步、权限过滤、或软删除状态差异

### BUG-INV-03 同品 GP20 数量/日期/序列号不一致
- **筛选**：产品名称 `GP20`
- **新站**：GP20-1C1H/UH，数量 **3/5**，生产日期 **2026-01-12**，序列号有值；租赁参考价可见
- **旧站**：同型号 1 条，数量 **0/1**，生产日期空，序列号摘要空；展开明细见 `KC2024090015`，生产日期 `2024-09-01`，状态「租赁出库」
- **影响**：同一产品型号两边库存状态对不上，易导致租用决策错误
- **建议**：核对聚合逻辑（多库存号合并）、生产日期字段来源、出库后数量展示规则

## P0 / 高 — 筛选功能缺陷

### BUG-INV-04 新站「实验平台」下拉无数据
- **站点**：新站
- **现象**：实验平台筛选项打开后仅显示「无数据」，无真实可选平台
- **旧站对照**：约 **47** 个真实选项（含 Line01/02/03、Gemini360、Sigma300 等）
- **影响**：新站无法按实验平台筛库存
- **建议**：检查平台字典/接口是否未接、权限或空数组前端兜底文案

### BUG-INV-05 旧站实验平台有选项但查询可能无结果（待产品确认）
- **站点**：旧站
- **现象**：选择「光伏逆变器测试实验线 Line01」，其它条件清空后查询 → **0 条**
- **影响**：若该平台下本应有库存（新站行数据里出现过平台相关值如 `0001-1`），则为筛选/关联错误；若确实无数据则为数据问题
- **建议**：用已知带平台的库存编号反查，确认平台字段映射

## P1 / 中 — 交互与展示

### BUG-INV-06 新站「清空筛选」不自动重新查询
- **站点**：新站
- **现象**：清空后控件恢复，列表仍停留在筛选结果；需再点「查询」才恢复约 326 条
- **对照**：与「实验室人员产出计划设定」页清空行为相同
- **建议**：清空后自动查询，或明确提示

### BUG-INV-07 旧站缺少「清空筛选」
- **站点**：旧站
- **现象**：仅有「清空勾选」；筛选条件需手动清空后再点查询
- **新站对照**：有「清空筛选」按钮
- **建议**：补齐清空筛选，或产品确认不需要

### BUG-INV-08 列表列集合不一致（产品决策）
- **新站列表列**：库存编号、商品名称、产品型号、产品厂家、数量、序列号、自用相关实验平台、租赁参考价、内部租赁价、生产日期；明细在行展开（仓库、位置、状态、公司、备注、编辑等）
- **旧站列表列**：上述核心列 + **所属公司、所在仓库、保存位置、设备成色、库存状态、自用租赁、备注** 等直接在表内
- **命名差异**：厂家/厂商；自用相关实验平台 / 自用租赁实验平台
- **建议**：明确迁移后以「主表精简 + 展开明细」还是「宽表」为准并文档化

### BUG-INV-09 旧站进入库存可能二次登录
- **现象**：控制台已登录时，打开 `/console/inventory/inventoryList.htm` 仍可能出现独立登录墙
- **影响**：UAT/联调体验差，自动化与人工对比易中断
- **建议**：统一会话/单点；或文档说明库存子系统需单独登录

## P2 / 低 — 体验差异

### DIFF-INV-01 默认排序不同
- 新站与旧站首页首屏商品序列不同（在数据范围未统一前可暂缓）

### DIFF-INV-02 行交互
- 新站：行展开/收起查看明细；无独立「查看」按钮
- 旧站：同样可展开；工具栏含编辑、生成二维码、导出等（本次未测编辑保存）
