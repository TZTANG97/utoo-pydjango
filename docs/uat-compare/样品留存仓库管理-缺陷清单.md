# 愉兔检测管理平台 UAT — 样品留存仓库管理 对比缺陷清单

- 对比日期：2026-09-14
- 新站：https://uat.utoodev.laide.tech/#/admin/inventory/sample-retain-warehouses  
  （库存管理 → 样品留存仓库管理）
- 旧站：console → 库存管理 → 样品留存仓库管理（已登录可见列表）
- 抽样：编号 `1` / 名称 `111ee额`

---

## P0 / 高

### BUG-SRW-01 地址/电话字段疑似错位
- **现象**：同仓 `1` / `111ee额`
  - 新站：手机为空；**地址** = `12333333333`
  - 旧站：联系电话为空；**注册地址** = `12333333333`；备注 = `1`
- **影响**：11 位数字更像电话，落在地址/注册地址易误导业务
- **建议**：核对迁移映射与表单字段绑定（手机 vs 地址）

---

## P1 / 中

### BUG-SRW-02 新站表格列被「操作」列遮挡
- **现象**：状态/创建时间在 DOM 中存在，但被固定操作列挤出可视区域
- **建议**：调整列宽/横向滚动/固定列策略

### BUG-SRW-03 列表字段模型不一致
| 新 | 旧 |
|---|---|
| 仓库编号/名称、负责人、手机、地址、**状态**、**创建时间**、操作 | 样品仓库编号/名称、负责人、联系电话、**注册地址**、**备注**、操作 |

文案：新增仓库 vs 添加样品仓库；停用 vs 禁用。
