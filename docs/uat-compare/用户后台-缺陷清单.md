# UAT C端用户后台缺陷清单

测试站点：`https://uat.utoodev.laide.tech/`

## P1

### UTOO-C-ORDER-FILTER-001：订单状态页签全部返回空，和“全部”数据不一致

> **状态（2026-09-15）**：已在 PR #3 修复并 merge 进 `dev`（`d8b0b00f`）；待 UAT 部署后复验。原复现记录保留。

- **位置/路由**：`#/b/order`
- **复现**：进入“全部”可见多条真实订单，状态字段包含“待支付”“待邮寄”“处理中”等；依次点击“全部、待支付、待实验、实验中、已完成、售后”。
- **实际**：五个筛选页签（待支付、待实验、实验中、已完成、售后）都切换高亮成功，但列表均显示“暂无数据/共0条”；“全部”页签有数据。
- **预期**：按状态返回与“全部”中状态字段匹配的订单；至少待支付页应包含 `TZPTUUU20260100001` 等待付款订单，已完成/处理中相关订单也应可被筛出。
- **影响**：用户无法通过一级状态筛选找到已存在的订单，属于核心订单列表功能异常。
- **证据**：空筛选“全部”首屏有 10 条、分页共 13 页；五个状态筛选页签均为 0 条，而“全部”页签有数据。真实订单号精确检索仍可返回单条，说明数据存在且列表接口并非完全不可用。

## P2 / 观察项

### UTOO-C-DISCUSSION-CONTENT-002：喜欢/收藏中的部分帖子疑似测试数据或内容质量异常

- **位置/路由**：`#/discussionNotes`
- **实际**：三个页签均可加载，部分帖子标题/正文包含大量重复文字、超长文本或测试标题；图片区域出现“暂无图片”占位。
- **影响**：不阻断连通性，但影响用户内容质量与展示观感。建议确认是否为预置 UAT 数据，若非预期需清理或限制文本展示。
