# 系统管理-缺陷清单

## UAT 观察到的问题

1. **新站管理端登录阻塞（已解决）**
   - 历史现象：新站普通入口回落公众站，原登录入口仅显示微信扫码登录/注册。
   - 当前结果：主机预填管理端登录表单可成功登录并进入管理仪表盘；「系统管理」及目标路由均可访问。
   - 结论：原阻塞不再复现，但后续回归应保留管理端入口/预填登录方式。

2. **区域数据重复（新旧站均可见，待确认是否业务数据问题）**
   - 现象：「区域管理」列表存在至少两个“华东”，时间不同。
   - 影响：公司区域筛选、选择和数据维护可能产生歧义。
   - 建议：确认是否为不同内部 ID 的合法区域；若非必要，合并或增加唯一标识。未在 UAT 中删除既有数据。

3. **菜单管理与账号操作具备高风险写入口（风险提示，非已复现缺陷）**
   - 新站用户、角色、菜单、部门、公司和账户页面均提供编辑/删除/禁用或权限入口。
   - 本轮仅读盘点；未禁用当前管理员、未修改角色/菜单、未删除业务数据。建议生产权限继续做二次确认/审计。
