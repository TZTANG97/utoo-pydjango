# 系统管理-缺陷清单

## UAT 观察到的问题

1. **新站管理端不可达（阻塞）**
   - 现象：新站根路径及提示路由均回落到公众站；`#/login` 仅显示微信扫码登录/注册，没有用户名密码管理端入口。
   - 影响：无法在新站验证系统管理菜单、筛选、CRUD，也无法完成新旧页面对比。
   - 建议：提供新站管理控制台 URL/账号或可用的测试登录方式。

2. **旧站区域数据重复**
   - 现象：「区域管理」列表中出现至少两个“华东”。
   - 影响：公司区域筛选存在歧义，数据维护/选择可能混淆。
   - 建议：确认是否为不同内部 ID 的合法区域；若非必要，合并或增加唯一标识。

3. **旧站用户类型新增表单的独立直达提交路径异常（探测性）**
   - 现象：从表单直达页填写临时数据并点击保存后，浏览器提交到不存在的嵌套路径并返回 404；未创建记录。
   - 影响：直接访问新增页时无法完成保存；需确认这是 iframe/base 路径依赖还是表单 action 配置问题。
   - 建议：在控制台 iframe 内复测表单 action，确保相对路径不会拼接成重复的 `sys/userType`。

## 安全/数据完整性记录

- 未禁用或删除当前登录管理员。
- 未修改用户、角色、菜单、部门、公司或已有地址/账号记录。
- 区域新增框仅填写临时名称，未提交；用户类型新增表单提交未落库（404）。
- 操作日志仅只读观察。
