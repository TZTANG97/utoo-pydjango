## 旧站复核

旧站 `/#/admin/fund/account` 内容区为空；直接访问历史 `/console/funds/assetAccount.htm` 在本轮仍有效的旧站页会话中直访并再次返回 HTTP 404；之后会话回到登录页（详见 `资金账户-缺陷清单.md`）。
