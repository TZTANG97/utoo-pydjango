# 运营管理-缺陷清单

## OPS-01（P2）图片地址清空提示与实际结果不一致

- 页面：新站 `/#/admin/ops/setting-rent`、`/#/admin/ops/setting-secondhand`。
- 复现：图片地址填写 `https://example.com/uat-test-rent.png` 并保存成功；随后清空输入框并保存。
- 实际：保存瞬间出现“请填写图片地址”提示；但重新进入租赁仪器设置和二手仪器设置，字段均为空、预览为“暂无图片”，测试值已清理。
- 期望：若空值是合法的清理动作，不应显示必填错误；若空值不合法，应阻止写入且保持原值。当前提示与最终状态矛盾，容易误判 cleanup 失败。
- 影响：低风险，但 UAT 探活结果不透明；建议统一前端校验与后端保存规则。

## OPS-02（P2，差异记录）旧站独有“商城商品列表”

- 旧站运营侧栏存在“商城商品列表”，新站运营侧栏没有对应项目。
- 该菜单属于商品域，已按用户要求视作产品管理覆盖项而跳过深测；若运营侧栏需要保留，应补齐新站菜单/路由或明确下线迁移方案。

## 非缺陷观察

- 新站“`小程序加载页面配置`”是实际侧栏名称，用户预期的“小程序封面轮播”不是当前展示文案。
- 评论/帖子列表中的通过、删除、上架、下架等控件均可见可操作；为避免改动非 UAT 数据，评论通过/删除和兑换确认发货仅做控件/详情核对。
