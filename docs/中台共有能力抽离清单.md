# 中台共有能力抽离清单

> 对照源：`E:\qd\mall_qingdao`（内嵌 `utexperiment*` 等）  
> 落地目标：本仓网关 + `qd_svc_*`（不另起仓库）  
> 策略：[愉兔与青岛商城中台抽离流程.md](./愉兔与青岛商城中台抽离流程.md)（**中台优先；商城暂不重构**）  
> 能力总表：[中台能力清单.md](./中台能力清单.md)

**状态取值：**

| 状态 | 含义 |
|------|------|
| 未收口 | 逻辑可能仍分散在网关 twin / 未强制走 svc |
| 对内可用 | 愉兔管理端/C 端可走中台路径（含试点中） |
| 对外可调 | 已具备对外契约与通道约定，可供以后商城调用 |
| 不抽离 | 青岛本域或明确排除 |
| 冻结 | 等商城重构启动后再做接入/下线 |

## 2. 不抽离（青岛本域）

| 商城模块 | 说明 |
|----------|------|
| 销售单 / 购物车 / 前台商城 | 电商本域 |
| 租赁 / 借租 / 采购 | 电商/供应链本域 |
| 厂内 AMK / Emku 产品单 | 工厂域；品牌「愉兔」标签不算中台能力 |
| `/experimentOrder`（非 UT 青岛实验栈） | 青岛自有实验栈；与 `ut*` 区分，除非业务确认合并 |
| 内部 WMS / 存货销售主体 | 留商城；与中台库存同步点另议 |

---

## 3. 工程落地顺序（本仓，商城零改动）

1. **P0 订单**：开 `SVC_ORDER_URL`；主路径只打 `qd_svc_order`；冻结网关 twin 新业务。  
2. **P1 数字化读**：资产域 UT 统计/下钻只读 API 对齐。  
3. **M3 对外就绪**：路径清单 + 鉴权/`X-Channel`；curl/脚本验证；**不改 mall**。  
4. **P2**：主数据与实验室/库存绑定。  
5. **M4+**：仅当宣布商城重构后，商城改调中台并下线双写。
