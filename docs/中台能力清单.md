# 中台能力清单

> 对内中台：管理后台（`qd_admin_front`）、C 端（`qd_test_front_v3`）、微信等端经网关共用域服务。  
> 新需求先查本表回答「进哪个服务、谁调用」。

## 服务一览

| 服务 | 端口 | 职责 |
|------|------|------|
| `qd_test_server_django`（网关） | 18083 | 路由转发 + **后台登录** + **C 端认证**（`admin_auth` / `auth_pc`） |
| `qd_svc_order` | 18082 | 实验订单、子单、复测、咨询、后台实验管理 |
| `qd_svc_payment` | 18084 | 支付/资产 + **微信扫码/预约/反馈**（4 个 `/api/wx`）；小程序登录等在网关 `wx_mp` |
| `qd_svc_admin_asset` | 18090 | 数字化、库存、资金 |
| `qd_svc_admin_platform` | 18091 | 系统/会员/运营/服务平台/订单设置 + 入驻/发票 |
| ~~`qd_svc_auth`~~ | ~~18081~~ | **已废弃** → 并回网关 |
| ~~`qd_svc_wx`~~ | ~~18087~~ | **已废弃** → 并入 `qd_svc_payment` |
| ~~`qd_svc_invoice` / `qd_svc_entry`~~ | — | **已废弃**，并入 `qd_svc_admin_platform` |

环境变量：`SVC_ORDER_URL` / `SVC_PAYMENT_URL` / `SVC_WX_URL`（与 payment 同指 **18084**）/ `SVC_ADMIN_ASSET_URL` / `SVC_ADMIN_PLATFORM_URL`；入驻/发票 → **18091**。**勿设** `SVC_AUTH_URL`。

## 纪律（写代码前必读）

1. **新功能只进负责服务**，网关仅加路由/转发装饰器，不写领域逻辑。  
2. **禁止** `qd_svc_*` 之间直接 `import` 对方业务模块；跨域用 HTTP 或 Celery。  
3. 管理端与 C 端 UI 可以不同，**同一业务状态变更必须走同一服务方法**。  
4. 差异用角色 / 配置 / 请求头 `X-Channel`（见 [中台身份与菜单约定.md](./中台身份与菜单约定.md)），**不按端拆服务**。
