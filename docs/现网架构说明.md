## 3. 双机拓扑

```text
UTOO 前端 / 小程序 ──► utoo_gateway :18083
                            ├─ identity :19081（基础登录/用户读）
                            ├─ utoo_biz :18093（愉兔独有业务）
                            ├─ order / payment / asset / platform
                            └─ 菜单/me 拼装（方案 B，在网关层）

青岛 admin-web ──► mall gateway :18080
                    ├─ identity（基础登录/组织写）
                    ├─ mall :18092（经营）
                    ├─ order VIP（实验单白名单）
                    └─ 青岛菜单树拼装（方案 B，在 gateway/mall）

两端 Redis / Celery 不共用。数据库同一 RDS `qd_pt_new`。
```

青岛 `gateway/.env` 示例：

```env
UTOO_ORDER_SERVICE_URL=https://uat.utoodev.laide.tech
IDENTITY_MID_SERVICE_URL=https://uat.utoodev.laide.tech
# 仅本机联调：
# UTOO_ORDER_SERVICE_URL=http://127.0.0.1:18082
# IDENTITY_MID_SERVICE_URL=http://127.0.0.1:18110
```

青岛网关把 login/me/refresh/password/data-scope/menus/permissions 以及 `users`/`roles`/`departments`/`menus` 拼成 `{IDENTITY_MID_SERVICE_URL}/api/v1/identity/...`。菜单写按 `pt_type` 过滤（青岛 `1`、UTOO `2`），错平台当 404。UTOO 公网 Nginx `/api/` 进网关后白名单转发到 `SVC_IDENTITY_URL`（`:19081`）。

## 4. 身份与菜单

中台代码：`utoo-pydjango/qd_svc_identity`，前缀 `/api/v1/identity/`。

| `X-Channel` | 账号 | 菜单 |
|-------------|------|------|
| `mall_qd` | `sy_users` | `role.type=1` 且 `pt_type` 含 `1` |
| `admin` | `sy_users` | `role.type=2` 且 `pt_type` 含 `2` |
| `pc` / `wx` | `exp_user` | **空数组**（C 端不拉 `sy_menu`） |
| `emku` / `factory` | — | 一期 **400** |

缺省 / 未知 Channel → **400**。`X-Channel` 只选登录入口和投影菜单，**禁止**用来表示蓝绿槽。

JWT：UTOO `JWT_SECRET_KEY`；青岛壳 `MALL_JWT_SECRET` / issuer `qd-mall-identity`。两端 axios 带 `Authorization: Bearer` 与兼容头 `token`。

### 开关

| 端 | 变量 | 行为 |
|----|------|------|
| UTOO 网关 | `SVC_IDENTITY_URL` | 非空则密码登录 / me / 菜单转发中台；并挂公网 `/api/v1/identity/*` 白名单（青岛 VIP） |
| 青岛 gateway | `IDENTITY_MID_SERVICE_URL` | 非空则 login/me/refresh/menus/permissions 与 users/roles/departments → 中台 |

发版：GitLab `deploy_identity_*`，先 identity 再 gateway。见 `utoo-pydjango/deploy/README.md`。

### 回滚

- **UTOO**：清空 `SVC_IDENTITY_URL`，重启**当前**网关槽 → 回退网关 twin。公网 `/api/v1/identity/*` 会 503。
- **青岛**：清空 `IDENTITY_MID_SERVICE_URL` **不能**回退登录（本地 LoginView 已 410）。紧急回退：identity 设 `IDENTITY_DISABLE_LOCAL_LOGIN=false` 并清空 MID URL，重启 identity + gateway。

## 5. 网关转发

日常可不配 `SVC_*_URL`（业务在网关 twin）。UAT/生产核心域必须配，上游未启则 **503**。

UTOO 网关 `.env`：

```env
# 勿设 SVC_AUTH_URL
SVC_IDENTITY_URL=http://127.0.0.1:18110
# 生产/UAT 本机 Nginx：
# SVC_IDENTITY_URL=http://127.0.0.1:19081
SVC_ORDER_URL=http://127.0.0.1:18082
SVC_PAYMENT_URL=http://127.0.0.1:18084
SVC_WX_URL=http://127.0.0.1:18084
SVC_ADMIN_ASSET_URL=http://127.0.0.1:18090
SVC_ADMIN_PLATFORM_URL=http://127.0.0.1:18091
SVC_INVOICE_URL=http://127.0.0.1:18091
SVC_ENTRY_URL=http://127.0.0.1:18091
```

改 `.env` 后须重启网关。实现：`apps/core/svc_proxy.py`。

**仍留网关**：短信/微信一键、公众号 XML 回调 `wechatconfig.ajax`、JWT 校验、转发层。

## 6. 能力归属（新功能先查这张表）

| 能力 | 服务 | 路径前缀 |
|------|------|----------|
| 密码登录 / 菜单 / 权限 | `qd_svc_identity` | `/api/auth/*`、`/api/vue/userLogin.ajax`、`main.ajax` → `/api/v1/identity/` |
| 实验订单 / 子单 / 复测 / 咨询 / 后台实验 | `qd_svc_order` | `/api/experimentOrder/*`、`/api/adminExperiment/*` |
| 支付 / 充值 / 微信扫码预约反馈 | `qd_svc_payment` | `/api/pc` 支付、`/api/wx` 扫码 4 接口 |
| 数字化 / 库存 / 资金 | `qd_svc_admin_asset` | `/api/digital/*`、`/api/inventory/*`、`/api/funds/*` |
| 系统会员运营 / 入驻 / 发票 | `qd_svc_admin_platform` | `/api/sys/*`、`/api/entry/*`、`/api/invoice/*` |
| 小程序资料/一键等 | 网关 `wx_mp` | `/api/wx/*`（非扫码 4 接口） |

纪律：新功能只进负责 `qd_svc_*`；禁止微服务互相 import 业务模块；同一状态变更走同一服务。差异用角色 / `pt_type` / `X-Channel`，不按端拆服务。

表写归属（共库 `qd_pt_new`，每张核心表一个写服务）：订单族 → order；支付落库 → payment；库存资金 → asset；会员/系统用户角色菜单/入驻发票 → platform。登录签发在 identity；青岛组织写仍 mall identity。
