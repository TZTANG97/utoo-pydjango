试验条件怎么填（通用）

各试验对话框第一步大多相似。本页讲清：单相/三相、直流勾几个、等待时间与启机时间、功率分析仪怎么选。具体试验还有专属参数，见左侧对应试验页的「示例一套」。

默认电网示例一律按 230 V、50 Hz 写。若现场额定是 220 V / 60 Hz 等，把数字改成现场值即可，填法不变。

一、交流 · 单相怎么填

  1. 「交流电源」选 开启。
  2. 「相位」选 单相。
  3. 交流电压1 填 230（单位 V）。
  4. 频率 填 50（单位 Hz）。
  5. 电压2、电压3：单相时一般不用管（可保持界面默认）。
项目示例填写
交流电源开启
相位单相
交流电压1230 V
频率50 Hz

二、交流 · 三相怎么填

  1. 「交流电源」选 开启。
  2. 「相位」选 三相。
  3. 交流电压1、2、3 都填 230（三相平衡的常用默认）。
  4. 频率 填 50。
  5. 需要故意做不平衡时，再按试验规程改某一相电压；日常并网试验多数三角相等。
项目示例填写
交流电源开启
相位三相
交流电压1 / 2 / 3230 / 230 / 230 V
频率50 Hz

三、直流电源 · 勾一个还是多个

  • 勾选某一路「直流电源1～4」= 软件会给这一路下曲线并控制开关。
  • 不勾 = 这一路不参与本次试验命令。
  • 勾几个：看逆变器实际接了几路直流源。只接了 DC1 → 只勾直流电源1；接了两路就勾 1 和 2，以此类推。
  • 第一次练手 / 短冒烟：建议 只勾 DC1，其它取消勾选，避免空通道报错。
  • 每路右侧「开启/关闭」：要出功率选 开启。

四、等待时间 和 启机时间 是什么意思

名称简单理解常见示例
等待时间 交流源「开输出」之后，先等这么久，让电压/频率站稳，再继续开直流等后续动作。 3 秒
启机时间 交流和直流都按设定开完后，再等这么久，让逆变器并上电网、功率起来，然后才进入录波或试验本体。 5 分钟（短冒烟可改成 30～60 秒）
两者都是「等多久」，但时机不同：等待偏「电网刚开出后稳住」；启机偏「整机起来后再测」。单位下拉里选「秒 / 分钟 / 毫秒」，数字和单位要匹配。

五、功率分析仪怎么选择和配置

试验对话框「功率分析仪」步骤顶部一般有两档，必须先选对：

  • 功率分析仪 (WT)：台架用横河 WT 时选这项，再选 WT3000 等型号。
  • DEWETRON（德威创）：台架用德威创时点选这项，下方会换成德威创配置页。
选哪边必须与设备管理里已连接的仪器一致。连了德威创却留在 WT，录不到德威创数据。
  1. 先在设备管理把 WT 或德威创连上（见左侧连接章节）。
  2. 打开试验 → 进入「功率分析仪」步骤。
  3. 用 WT：点「功率分析仪 (WT)」→ 选型号 → 设路径/文件名/连续录或分开录。
  4. 用德威创：点 DEWETRON → 刷新电力组/导出字段 → 勾导出项 → 点「测试生效/应用」。
  5. 全部填完后点 测试追加。改参数后要重新追加。
