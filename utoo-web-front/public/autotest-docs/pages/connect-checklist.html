设备就绪检查

进入任一试验前，建议快速过一遍：

  • 交流源：已连接；型号页正确（Chroma 串口/IP 或爱科 IP）。
  • 直流源：已连接；蓝电还需模式已应用、参数已下发（按工况）。
  • WT3000：在「设备管理 · WT3000」页已用 IP（或串口）连上；试验里的测量勾选另说。
  • 德威创：已 IP 连接；接线类型选对；U/I 通道已绑定；「保存」成功。OXYGEN 远程勿占连接。
  • DL850：若本试验用示波器，已在设备页连接。
  • 逆变器与台架安全：急停、接线、限值与规程确认完毕。
就绪后再打开 Auto_Test 对应试验对话框，按试验页步骤「追加 → 运行」。
