功率分析仪 · 德威创（DEWETRON）

入口：主界面左侧 →「德威创」。本页负责连上仪器、选接线方式、绑定电压/电流通道并保存配置。

试验对话框里若选「德威创模式」，前提是本页已经连接成功且通道绑定正确。OXYGEN 远程桌面占着连接时，软件往往连不上（通常只允许 1 个客户端）。

一、连接设备（先做）

  1. 确认电脑与德威创在同一网段，能 ping 通设备 IP。
  2. 若本机开着 OXYGEN / 远程桌面客户端连着同一台德威创，先退出，再在本软件连接。
  3. 在页面上方填写 IP地址（例：192.168.40.21）和 端口（常见 10001）。
  4. 点 「连接设备」。成功后按钮会变为「取消连接」，下方日志会提示已连接。

二、选择接线类型

顶部五个按钮对应不同电力接线，按台架实际接线选一个（选错会导致通道槽位数量不对）：

按钮含义常见场景
1P2W1 相 2 线单相 L-N
1P3W1 相 3 线单相带中线扩展
2V2A3 相 3 线（两表法）三相无中线部分工况
3P3W3 相 3 线三相三线
3P4W3 相 4 线三相四线（常见并网逆变器）

中间「接线图」会随类型切换；下方「组1 / 组2 / …」槽位数量也会变。先选对类型，再绑通道。

三、绑定通道（必做）

左侧「通道列表」里是仪器实际电压/电流通道（如 AI 1/U1、AI 1/l1）。把它们填进下方组槽位，软件才知道哪路电压对应哪相。

  • 双击左侧某个电压或电流通道：按顺序自动填入组1 → 组2 → 组3…
  • 右键通道：可指定加到某一组。
  • 双击下方已填好的输入框：取消该槽位绑定。
  • 电压通道只能绑到 U 槽，电流通道只能绑到 I 槽。

底部「对应关系」会显示当前绑定结果（如 U1: AI 1/U1）。有空槽位时点保存会提示未填全。

四、右侧设备参数

  • 设备 IP / 端口：与上方连接一致，便于核对。
  • 输入通道：频率等参考通道，一般跟组1 的电压通道（如 AI 1/U1）。
  • 最大刷新率：常用 Default；有特殊采样要求时再改。
  • 通道二次采样：常用 Auto。

五、保存与测试界面

  1. 通道都绑好后，点绿色 「保存」：把接线/采样配置应用到德威创。未连接时保存会失败。
  2. 「加载配置文件」：可加载以前存过的配置，少重复绑通道。
  3. 「测试界面构造」：按当前设备状态构造测试页（需已连接）；日常试验多数只需连接 + 绑通道 + 保存即可。
就绪标志：已连接；接线类型正确；对应关系里 U/I 都有通道名；「保存」成功。然后再去开具体试验，并在试验里选「德威创模式」（若该试验支持）。
