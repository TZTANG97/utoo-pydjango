IP / SCPI 怎么选

不同厂家设备，软件「设备管理」里填的不是同一种东西。先对照下表，再进对应子页看截图。

设备常用连接软件里填什么注意
Chroma 交流/直流 串口（VISA/SCPI）或 IP（TCP/SCPI） 串口资源名，或 IP+端口 串口页与 IP 页分开；别和爱科/蓝电混用同一套字段习惯
爱科交流 IP（Modbus TCP） IP + 端口 主要用 IP，不要去找 Chroma 那种长串口资源名
蓝电直流 IP（Modbus） IP + 端口 → 再选工作模式并下发参数 不止连上 IP；还要「应用模式」+ SAS/原始负载参数 + 开输出
DL850 / 德威创 / WT 厂家协议（多为 IP/专用） 按各页字段 试验前确认已勾选本试验要用的录波仪
「设备管理」是几乎所有试验的标准开头：电源与录波仪连好、状态就绪后，再进 Auto_Test 菜单打开具体试验。
