功率分析仪 · WT3000E

入口：主界面左侧 →「WT3000」。本页只负责把仪器连上软件。测量勾选、保存路径、录波时长等，在各试验对话框的「功率分析仪」步骤里配置，不要和本页混淆。

以前若看到标题是「WT3000 参数配置 / 追加测试」的大窗，那是试验参数页，不是设备管理连接页。连仪器请以本页为准。

一、怎么进

  1. 打开 SolarAutoTest 主界面。
  2. 左侧设备列表点 WT3000（首页设备卡片也可点进）。
  3. 按下面「网口」或「串口」方式连接。

二、网口连接（台架常用）

  1. 确认电脑与 WT 同一网段，设备面板上的 IP 已知（例：192.168.40.19）。
  2. 在 IP地址 框填写 IP；端口 常见为 5025（现场以设备/厂家说明为准）。
  3. 点 「连接设备」。
  4. 成功后按钮变为 「取消连接」；失败时检查网线、IP、端口，以及是否被其它程序占用。

页面顶部蓝底提示也写了：网口请填 IP 再连。

三、串口连接

  1. IP 地址留空（重要）。
  2. 在 波特率 下拉框选与仪器一致的波特率（常见 9600 等）。
  3. 在 接口 下拉框选串口/VISA 资源（如 ASRL3::INSTR）。
  4. 点 「连接设备」。

四、连接成功后可做什么

  • 切换闪变页面：已连接时可发测试命令，让仪器显示切到闪变相关页面（用于确认通信正常；不是每个试验都必须点）。
  • 需要断开时点 「取消连接」。

五、和试验里「功率分析仪」步骤的关系

位置做什么
本页（设备管理 · WT3000）填 IP/串口 → 连接 → 确认通了
试验对话框 · 功率分析仪步骤选 WT 型号、勾测量量、保存路径、停表时间、追加命令等

顺序建议：先在本页连上 WT → 再打开过载等试验 → 在试验里配录波参数 → 测试追加 → 运行。

就绪标志：本页已「取消连接」状态（表示连着）；试验对话框里选了 WT3000 且参数填完。若试验一直录不到数，先回本页确认是否真的连上。
