SolarAutoTest 台架操作手册

给试验人员用的操作说明。左侧按分类点试验，右侧看步骤和示例表。

建议顺序：先连设备 →「试验条件怎么填」（230 V / 50 Hz、直流勾选、等待/启机）→ 打开具体试验，按「示例一套」录入后追加运行。

怎么用本手册

  1. 左侧上方可搜索试验名称；点「☰ 目录」可收起/展开左侧菜单。
  2. 一、起始连接方式 → 设备就绪检查。
  3. 二、试验条件怎么填。
  4. 三、试验项目：与软件 Auto_Test 同名，按「电能质量 / 保护与重连 / 有功无功 / 适应性与 MPPT」分类。
  5. 打开试验后：点步骤一览里的条目可跳到对应步骤；右上角下载 PDF会直接下载本试验说明 PDF（不是打印）。

已覆盖的试验

电压闪变、谐波电流、过载能力测试、直流分量、固定 PF=1、重连、过欠压_过欠频、过频降载、欠频升载、10min过压保护、ROCOF保护、过欠频免疫、有功调度、防逆流测试、无功能力/定无功/注入/精度、静态/动态 Cos(φ)、静态/动态 QU、Test_PU、频率/电压适应性、快速电压变化、静态 MPPT。

菜单名以软件 Auto_Test 下拉为准。接线与限值以台架负责人为准。
