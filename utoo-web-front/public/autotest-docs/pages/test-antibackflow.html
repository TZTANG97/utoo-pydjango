防逆流测试 已就绪

菜单：Auto_Test → 防逆流测试。对应西班牙零馈网（UNE 217001 / anti-vertido）。先完成设备连接，再按「截图 + 说明」填写。

前置：交流源、直流源、功率分析仪（WT 或德威创）已在设备管理连好。本试验上位机只控电源与录波；切负荷 / 断开防逆流通讯在「人工操作等待」里由试验员现场完成。

② 功率分析仪

本步顶部两档，须与设备管理已连接仪器一致：

  • 功率分析仪 (WT)：再选 WT3000 / WT1800 / WT1806E / WT5000。
  • DEWETRON：刷新电力组 → 勾导出 → 测试生效 / 应用。

录波建议

  • 正式试验：优先 一条线连续录，文件名 AntiBackflow_BR。
  • 分开录时按工况段生成 AntiBF_… 文件名（软件自动推荐）。

③ 防逆流工况

勾选段上位机做什么试验员现场做什么
5.1 稳态DC 按 100/70/20/0 %Pn，每档驻留（默认 2 分钟）负荷保持与该档匹配的消费功率
5.2 切负荷前后各半窗驻留 + 人工等待窗口在等待窗口内按表切换负荷（90→60/30/0 等）
5.3 一次能源突增DC 45% → 90%负荷保持约 60～70%Pn
5.4 通讯丢失人工等待 + 短测窗断开防逆流通讯，观察限时停发（通常 ≤2 s）
项示例
稳态/半窗驻留2 分钟（标准窗约 2 min；冒烟可改秒）
人工操作等待30 秒（切负荷 / 断通讯够用即可）
录波方式一条线连续录 · AntiBackflow_BR
判定看 PCC 馈网功率是否超出零馈网限值；修正超时一般 ≤2 s。软件不改逆变器内部防逆流参数，机侧须事先按规程启用防逆流。

④ 关机设置

勾选关机步。习惯：先关直流，稍等，再关交流。填完点测试追加再运行；改参数须重新追加。

操作顺序（照做）

  1. 设备管理：连好 AC、DC（对应品牌）、WT 或德威创。
  2. Auto_Test → 防逆流测试 → 按①②③④填写。
  3. ② 分析仪型号 / 德威创模式与真实仪器一致。
  4. 点测试追加 → 开始试验。
  5. 跑到 5.2 / 5.4 时注意界面等待窗口，及时切负荷或断通讯。
  6. 结束后检查录波文件 AntiBackflow_BR（或分段文件）。
示例一套汇总：三相 230/50；DC1；等待 3 秒、启机 5 分钟；勾 5.1～5.4；驻留 2 分钟；人工等待 30 秒；WT 或德威创连续录 AntiBackflow_BR。
