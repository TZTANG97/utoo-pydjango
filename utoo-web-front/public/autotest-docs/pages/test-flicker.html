电压闪变 已就绪

菜单：Auto_Test → 电压闪变。先完成设备连接，再按下列「截图 + 说明」逐步填写。

前置：交流/直流/分析仪已连接。功率仪步骤请按台架选择 功率分析仪 (WT) 或 DEWETRON（德威创）。通用填法见「试验条件怎么填」。

步骤一览

  1. ① AC/DC 电源
  2. ② 闪变测量设置
  3. ③ DC 开关循环
  4. ④ 判定结果
  5. ⑤ 关机设置

① AC/DC 电源

电压框若为空请填 230/50。

本步填交流、直流和时序。通章说明见左侧「试验条件怎么填」。

② 闪变测量设置

本步顶部有两档（多数试验一样）：

  • 功率分析仪 (WT)：台架用横河 WT 时选这项，再选 WT3000/WT1800 等型号并配置。
  • DEWETRON（德威创）：台架用德威创时必须点选这一项，下方会换成德威创配置页（不要只停在 WT 页）。
选哪边，必须与「设备管理」里已经连上的仪器一致。连的是德威创却留在 WT，试验录不到德威创数据。

选 WT 时怎么配

  1. 点选「功率分析仪 (WT)」。
  2. 再选具体型号（如 WT3000）。
  3. 填保存路径、文件名；选「一条线连续录 / 分开录」。

选德威创（DEWETRON）时怎么配

  1. 设备管理里德威创已 IP 连接，且接线/通道已保存（见左侧德威创连接页）。
  2. 本步点选 DEWETRON。
  3. 点 刷新 电力组/导出字段。
  4. 勾选本试验需要导出的量。
  5. 点 测试生效 / 应用（名称以界面按钮为准）。
  6. 录波方式（连续录/分开录）按试验需要选。

③ DC 开关循环

按界面填循环时长、间隔、次数。默认循环次数常见 12；冒烟可改 2～3。

注意总时长上限（约 600 秒），超限则减小间隔或次数。

④ 判定结果

按所选 WT/德威创模式勾选判定步，正式试验核对规程限值相关项。

⑤ 关机设置

勾选关机步。习惯：先关直流，稍等，再关交流。填完后点测试追加再运行；改参数须重新追加。

示例一套汇总：230/50；DC1；等待 5 秒；启机 5 分钟；每组闪变 3 次；循环次数冒烟可改小。
